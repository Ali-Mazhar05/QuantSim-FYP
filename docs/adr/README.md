# Architecture decision records

One file per decision, named `NNNN-short-name.md`, one pull request per record. An accepted record overrides the default in the Iteration 2 guides; its owner posts the change in the team chat and in `docs/progress-log.md` the same day.

Format: **Status** (Proposed, Accepted, Superseded), **Date**, **Owner**, then **Context**, **Decision**, **Consequences**. Keep each record to one page. Change an accepted record only by a new record that supersedes it.
