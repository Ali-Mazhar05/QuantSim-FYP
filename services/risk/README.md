# Risk service

Generated by `scripts/new-service.sh risk`. Owner: see the lane guides.

## Processes (one image)

| Process | Command | Does |
|---|---|---|
| API | default (`uvicorn qs_risk.main:create`) | Routes under `/api/risk`, behind the gateway |
| Worker | `python -m qs_risk worker` | Claims jobs from the `job` table and runs their handlers (`qs_template.jobs`) |
| Relay | `python -m qs_risk relay` | Publishes outbox events to Redpanda |
| Migrate | `alembic upgrade head` | Runs before each deploy |

## Where things go

| File | Put here |
|---|---|
| `src/qs_risk/domain/` | Pure functions, no I/O |
| `src/qs_risk/api.py` | Routers, added to `build_routers` |
| `src/qs_risk/jobs.py` | Job handlers, registered in `HANDLERS` by kind |
| `src/qs_risk/models.py` | Tables; add a migration in `migrations/versions/` for each change |

## Run the checks

```bash
ci/scripts/python-ci.sh services/risk

```
