# Simulation service

Generated by `scripts/new-service.sh simulation`. Owner: see the lane guides.

## Processes (one image)

| Process | Command | Does |
|---|---|---|
| API | default (`uvicorn qs_simulation.main:create`) | Routes under `/api/simulation`, behind the gateway |
| Worker | `python -m qs_simulation worker` | Claims jobs from the `job` table and runs their handlers (`qs_template.jobs`) |
| Relay | `python -m qs_simulation relay` | Publishes outbox events to Redpanda |
| Migrate | `alembic upgrade head` | Runs before each deploy |

## Where things go

| File | Put here |
|---|---|
| `src/qs_simulation/domain/` | Pure functions, no I/O |
| `src/qs_simulation/api.py` | Routers, added to `build_routers` |
| `src/qs_simulation/jobs.py` | Job handlers, registered in `HANDLERS` by kind |
| `src/qs_simulation/models.py` | Tables; add a migration in `migrations/versions/` for each change |

## Run the checks

ci/scripts/python-ci.sh services/simulation
