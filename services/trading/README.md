# Trading service

Generated by `scripts/new-service.sh trading`. Owner: see the lane guides.

## Processes (one image)

| Process | Command | Does |
|---|---|---|
| API | default (`uvicorn qs_trading.main:create`) | Routes under `/api/trading`, behind the gateway |
| Worker | `python -m qs_trading worker` | Claims jobs from the `job` table and runs their handlers (`qs_template.jobs`) |
| Relay | `python -m qs_trading relay` | Publishes outbox events to Redpanda |
| Migrate | `alembic upgrade head` | Runs before each deploy |

## Where things go

| File | Put here |
|---|---|
| `src/qs_trading/domain/` | Pure functions, no I/O |
| `src/qs_trading/api.py` | Routers, added to `build_routers` |
| `src/qs_trading/jobs.py` | Job handlers, registered in `HANDLERS` by kind |
| `src/qs_trading/models.py` | Tables; add a migration in `migrations/versions/` for each change |

## Run the checks

```bash
ci/scripts/python-ci.sh services/trading

```
